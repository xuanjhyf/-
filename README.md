# 课件专家 · 中学语文智能备课 Agent

作者：何雨霏（独立产品 + 研发 + 评测）

这是 kejian-expert（课件专家 v1.16.0）的交付档案。它从最早一个只会出演示页的东西，做到现在能在本地独立部署、跑通"认课文 → 扫素材 → 定风格 → 出课件 → 出教案"，中途踩了 15 个生产环境才会遇到的坑，每个都记成了「问题 → 根因 → 解法 → 验证」。

仓库里放四块内容：15 项整改复盘、30 题垂直评测集、架构与接口说明，和一份评测报告。

## 这个 Agent 做什么

输入一句话（比如"备必修上册第六单元的《劝学》，两课时"），它内部走一套流程：

```
认课文+课标 → 扫素材 → 定风格 → 出课件 → 质量门禁
   (RAG 双库绑定)                        (check_gate 校验)
```

- 认课文：自动识别"册次 / 单元 / 课时"，支持跨册
- 扫素材：上传模板、图片、配色，落库可查
- 出课件 / 教案：端到端生成，质量门禁兜底
- 学情分析：初中 / 高中两套技能，绑定班级成绩

## 技术栈

- 后端：Flask + SQLite
- 前端：单文件 index.html（可独立演示）
- 部署：Docker / docker-compose / start.bat + start.sh
- 自动化：9 个 verify 脚本（前端、API、GBK、启动、优雅停机、Docker）
- AI：RAG（内置知识库 + 个人库）、Coze / WorkBuddy / 即梦等

## 从"事件的零岁"到"课件专家"

最早做「事件零岁」，一个单 Agent。一点一点把它推成端到端、能部署、能观测的产品。最大的变化是认知：改接口协议、处理 Windows 换行符/GBK 编码、给 pipeline 每一步配 try/except，这些在演示页里都不会遇到，只有真的想让别人能跑起来才会碰到。
